# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `office_docs_mcp`, please report it responsibly rather than opening a public issue.

Please report security issues via GitHub Private Vulnerability Reporting or contact the project maintainers directly.

We appreciate your assistance in keeping `office_docs_mcp` safe and secure for the community.
